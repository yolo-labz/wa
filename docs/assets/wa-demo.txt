$ wa msg revoke --help
Revoke removes a message. --scope=self deletes it for YOU — a deleteMessageForMe app-state mutation your own devices act on, which no peer ever sees. --scope=everyone (default) emits a ProtocolMessage REVOKE so peers delete their copy. Neither is reversible.

Usage:
  wa msg revoke [flags]

Flags:
      --chat string              chat JID
  -h, --help                     help for revoke
      --idempotency-key string   FR-034a replay key; same key + params replays cached result, same key + different params returns -32101
      --messageId string         message ID to revoke
      --scope string             revoke scope: self|everyone (default "everyone")

Global Flags:
      --json             output NDJSON instead of human-readable text
      --profile string   profile name (see 'wa profile list')
      --remote string    remote daemon URL (e.g. https://wa.example.com); incompatible with --socket
      --socket string    path to wad unix socket (default "/tmp/wa-demo.rwgcQK/run/wa/default.sock")
      --verbose          enable verbose output
      --version          print the wa CLI version and exit
